# Task Management System

A task management web application built with a Python backend and a frontend interface (`HTML`, `CSS`, `JavaScript`) to create and organize tasks.

## Project Structure

- `Backend/` — Application and database logic (`App.py`, `db.py`)
- `Frontend/` — User interface files (`index.html`, `style.css`, `script.js`)
- `requirements.txt` — Python dependencies
